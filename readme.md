# 「あなたが繰り返すミスのクセ診断」（調剤・監査・確認業務編） 設計書

## プロジェクト概要
本プロジェクトは、PM理論の考え方を土台にしながら、薬剤師の調剤・監査・確認業務における「自分の思考のクセ」や「無意識のバイアス（ミスを起こしやすい行動パターン）」を可視化し、診断結果に応じて具体的な改善行動を提示するWEBサイトを構築するものである。

このサイトの目的は、単なる性格診断や理論解説ではない。  
診断を通して、利用者が**自分の業務上の傾向に気づき、明日からの現場で1つ行動を変えられる（ミスの予防につながる具体的な行動をとれる）状態になること**をゴールとする。

---

## 1. このプロジェクトの本質
本プロジェクトの本質は**「薬剤師が持つ強みの暴走によって発生する業務上の判断ミスや監査時の見落とし（思考のクセ）を可視化すること」**である（「薬剤師の業務上の思考バイアス診断」への進化）。

このサイトは性格診断ではない。また、単なる調剤スキルの診断でもない。
薬剤師が良かれと思って、あるいは無意識のうちに繰り返して起こしやすい**「思考バイアスと行動パターン」**を可視化し、明日からの現場での具体的な行動変容につなげるための教育・実践ツールである。

## 2. 想定ユーザー
### 主ペルソナ
- 病院・薬局を問わず、調剤・監査・確認業務を行う薬剤師

### 副次的な閲覧対象
- 他の医療従事者
- 医療安全管理に関心のある人
- 教育担当者（管理薬剤師、主任、指導薬剤師）
- AIやDXを医療教育に応用したい人

### 基本方針
表向きの設計は広く読める形にしつつも、**軸は薬剤師の現場感覚に置く**。  
一般向けに薄めるのではなく、**薬剤師目線を主軸にした翻訳設計**で構成する。

## 3. サイトの中心ゴール
### コアゴール
- 自分の仕事のタイプ（強みと弱点）に気づく
- 自分の調剤・監査における「ズレ（ミスのクセ）」に気づく

### メインの行動ゴール
- 明日からの調剤・監査の確認行動を1つ変える（具体的なチェック方法を導入する）

### サブゴール
- 自分の弱点・行動変容をメモ・保存できる
- 業務ストレスやミスに対する不安の軽減につながる
- 教育ツール・院内勉強会資料（自己分析シート）として活用できる
- AI・DXに興味を持つきっかけになる

### 重要な考え方
このサイトは「診断して終わり」では意味がない。  
必ず、**診断 → 気づき → 行動**までを一気通貫で設計する。

## 5. 理論ベースの方針
### 基本思想
裏側はPM理論の構造を使う。  
ただし、表に見せるのは理論用語ではなく、**現場に刺さるオリジナルのタイプ表現**とする。

### 採用方針
- 裏：PM理論ベース
- 表：完全オリジナルの6タイプ表現
- 実装：PM理論の型を基盤にしつつ、現場のクセ言語へ翻訳する

### なぜこの設計にするか
PM理論そのままでは学術的すぎて現場に刺さりにくい。  
一方で、完全オリジナルだけにすると理論的な芯が弱くなる。  
そのため、**裏に理論、表に実践言語**という二層構造を採用する。

## 6. 診断タイプの基本方針
### タイプ数
- 6タイプ（ゴールマンのリーダーシップスタイルに基づく調剤・監査業務翻訳）

### 設計思想
6タイプは「性格類型」ではなく、**調剤・監査・確認業務で起こりやすい失敗パターンの類型**として設計する。

### 確定した6タイプと起こしやすいミス（調剤・監査版）
各タイプは「強みの暴走」によって以下のようなミスや行動上のズレを引き起こしやすい。この対応関係は、すべてのコンテンツの親設計となる。

1. **🔥 ペースセッター型**（説明しすぎ・引っ張りすぎ型）
   - **起こしやすいミス**: 焦りによる見落とし / ダブルチェック省略 / 流し読み
2. **🧭 コーチ型**（見守りすぎ型）
   - **起こしやすいミス**: 介入不足 / ミスの見逃し / 指導・指摘の遅れ
3. **⚡ 強制型**（正解を急ぎすぎ型）
   - **起こしやすいミス**: 過去の経験への固執 / 処方の決めつけ / イレギュラー変更の見落とし
4. **💛 関係重視型**（嫌われたくない・なあなあ型）
   - **起こしやすいミス**: 疑義照会の躊躇 / 医師や他者への過度な気遣いによる確認漏れ / なあなあ対応
5. **🔮 先見型**（理想・未来語りすぎ型）
   - **起こしやすいミス**: 未来の治療イメージ優先による現状の規格・数量ミスの見落とし / 地味な確認作業の軽視
6. **🗳️ 民主型**（選択肢・丸投げ型）
   - **起こしやすいミス**: 判断の先延ばし / 同僚への意見依存 / 曖昧なままの作業滞留

## 7. 診断後に必ず出す要素
各タイプの診断結果ページ、もしくは診断結果表示欄には、以下を統一フォーマットで出力する（結果画面では、ユーザーの痛いところに刺さる「ミス先行型」の順序で並べる）。

1. 起こしやすいミス3選（⚠️最上部に表示）
2. タイプ名と比率（単一タイプまたは複合タイプ）
3. ズレの指摘と理由解説
4. 職場での立ち位置 ＆ 新人指導での注意点
5. 相性の良いタイプ ＆ 相性の悪いタイプ
6. 傾向マップ（棒グラフ ＋ レーダーチャート）
7. 修正のためのOK行動（自己改善アクション）と対応する補助教材画像（NG/OK比較図）
8. 明日使える具体的なセリフや確認用アクション
9. 振り返りメモ欄 ＆ 今日から試す行動（チェックリスト）
10. 結果の保存・共有（PDF/画像ダウンロード/院内勉強会活用）

## 8. 行動アドバイスの粒度
### 方針
行動アドバイスは抽象論ではなく、**アクション・手順・セリフレベルの具体性**で出す。

### 採用レベル
- 具体（手順・チェック動作・発言レベル）

### 理由
現場では「考え方」だけでは行動が変わらない。  
必要なのは、明日の調剤台や監査台でそのまま実行できるレベルの修正アクションである。

### 例の方向性
- 「処方箋と監査画面を指で1文字ずつ指して突合してください」
- 「疑義照会をする前に、確認したいポイントを付箋に1行で書き出してください」
- 「イレギュラー処方で迷ったら、30秒以内に手順書（SOP）を確認するか上司に聞いてください」

## 10. スコアリングの設計方針
### 判定ロジック
6タイプそれぞれに対応する3問のスコアを直接合算し、最高スコアのタイプを判定する。

### 複合型判定
最高得点が **2タイプで同点**の場合、**「複合型（ハイブリッド型）」**として判定する。最高得点が **3タイプ以上で同点**の場合、**「複合傾向型」**として判定する。

### 比率（％）表示の算出
主タイプスコア $S_1$、副タイプスコア $S_2$ をそれぞれ正の値（0〜12）に変換し、その比率をパーセンテージで表示する。

## 12. 診断結果ページの構成案（Harvard Business Review風の実現）
利用者が「読んで終わる」ではなく、**自分の現場に置き換えて行動を変えたくなる状態**を作るため、以下の順序で構成する。
※結果ページ（HTML）と教材画像（NG/OK比較図）は完全に分離して考える。

### HTMLで動的に実装・描画するもの
- **タイプヘッダー**: あなたが最も起こしやすいミス（3選） ＆ タイプ名 ＆ 比率
- **理由解説**: 業務上の傾向・ズレの論理的解説
- **管理者視点 ＆ 新人指導アドバイス**: 職場での立ち位置
- **タイプ相性**: 相性の良い/悪いタイプの解説
- **バイアス傾向マップ**: 棒グラフ ＆ レーダーチャート（Chart.js等を使用）
- **自己改善チェック**: 明日からできる行動変容（OK行動）のチェックリスト、実践アクション
- **振り返りメモ**: `localStorage`に保存される自由記述欄
- **保存・印刷・共有**: 結果のA4 PDF印刷（院内勉強会用シート）、SNS共有ボタン

### 画像として挿入するもの（補助教材）
- **NG/OK比較図**: 1タイプにつき1枚（左右対比、4:3）。行動改善のヒントとしてHTML内の「行動変容セクション」に埋め込む。

## 13. 画像の役割と仕様
### 基本方針
画像は装飾ではなく、**ミスのクセに対する気づきと行動変容を促す補助教材**として使う。

### 基本仕様
- **基本比率**: 横長 4:3
- **レイアウト**: 左右分割構図（**左半分にNGシーン、右半分にOKシーン**）
- **テイスト**: 温かみのある手書き色鉛筆風のソフトなイラスト
- **仕様**: 1タイプにつき1枚（全6タイプ＝6枚）。結果ページの一部（改善行動の付近）に埋め込んで使用する。

---

## 14. 実装方針
### 想定技術構成
- **HTML/CSS/JS (Vanilla)**: 外部フレームワークを使わない、1枚のHTMLで完結する軽量なSPA構成。
- **データ設計**: 質問文や判定用スコア、タイプ別結果テキストはJSオブジェクトで管理。
- **グラフライブラリ**: Chart.js（CDN経由）を使用し、レーダーチャートと棒グラフを描画。
- **保存機能**: `localStorage` を使用した振り返りメモ・チェックリストの永続化。
- **PDF保存**: CSS `@media print` によるA4印刷用レイアウト制御。
